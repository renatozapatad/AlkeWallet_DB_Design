Proyecto: Diseno de Base de Datos Relacional - Alke Wallet
Aca subo el diseno, modelado y script de una base de datos para un monedero virtual llamado Alke Wallet. Este proyecto es parte de mi portafolio del bootcamp Full Stack Javascript Trainee en ISEG y muestra lo que se sobre bases de datos relacionales.

Lo que hice en este proyecto:
Diseno conceptual: Identifique las entidades y arme un diagrama ER.
Diseno logico: Normalice todo a la tercera forma normal (3FN).
Implementacion DDL: Cree las tablas, llaves primarias, foraneas y restricciones.
Datos y transacciones (DML): Inserte datos y probe envios de dinero usando los principios ACID (transacciones seguras).
Consultas SQL: Hice los select, join, update y delete necesarios.

Archivos del repo:
Base de datos AlkeWallet.docx: Mi reporte completo con todas las evidencias.
Modelo-Conceptual-ER-AlkeWallet.pdf: El diagrama visual inicial.
Esquema-Relacional-3FN-AlkeWallet.pdf: El modelo de tablas.
AlkeWallet.sql: El codigo completo listo para ejecutar.
